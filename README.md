# Claude Code Tutorial

비개발자를 위한 Claude Code 실습 튜토리얼 시리즈.

영상을 보고, 플러그인을 설치하고, 직접 따라 만들어보세요.

## 설치

Claude Code에서 아래 명령을 실행하세요:

```shell
/plugin marketplace add aiator/claude-code-tutorial
/plugin install claude-code-tutorial@aiator-claude-code-tutorial
```

## 사전 준비

- Claude Code 1.0.33 이상 설치 (`claude --version`으로 확인)
- Claude Pro, Max, Teams, 또는 Enterprise 플랜

> 영상이 올라올 때마다 스킬이 추가됩니다.

## 실습 방법

1. 유튜브 영상을 시청합니다
2. 플러그인을 설치합니다
3. Claude Code에서 `/claude-code-tutorial:260310-memory` 같은 슬래시 명령을 실행합니다
4. 스킬이 단계별로 안내하면 직접 따라 만듭니다
5. 완성된 결과물은 이후 실무에서 계속 사용할 수 있습니다

## 로컬 테스트

플러그인을 설치하지 않고 로컬에서 테스트하려면:

```bash
claude --plugin-dir ./claude-code-tutorial
```
