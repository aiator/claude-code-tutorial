# Claude Code Tutorial

비개발자를 위한 Claude Code 실습 튜토리얼 시리즈.

영상을 보고, 스킬을 설치하고, 직접 따라 만들어보세요.

## 설치

```bash
npx skills add aiator/claude-code-tutorial --agent claude-code --yes
```

개별 스킬만 설치하고 싶다면:

```bash
npx skills add aiator/claude-code-tutorial --skill 260310-memory --agent claude-code --yes
```

## 사전 준비

- Claude Code가 설치되어 있어야 합니다
- Claude Pro, Max, Teams, 또는 Enterprise 플랜 필요
- Node.js는 필요하지 않습니다

## 스킬 목록

| 날짜 | 스킬 | 주제 | 만들 것 |
|------|------|------|---------|
| 26.03.10 | `/260310-memory` | AI에게 나를 가르치기 | 내 업무 스타일이 담긴 CLAUDE.md |

> 영상이 올라올 때마다 스킬이 추가됩니다.

## 실습 방법

1. 유튜브 영상을 시청합니다
2. 스킬을 설치합니다
3. Claude Code에서 `/260310-memory` 같은 슬래시 명령을 실행합니다
4. 스킬이 단계별로 안내하면 직접 따라 만듭니다
5. 완성된 결과물은 이후 실무에서 계속 사용할 수 있습니다
