# Claude Code Tutorial

비개발자를 위한 Claude Code 실습 튜토리얼 시리즈.

영상을 보고, 스킬을 설치하고, 직접 따라 만들어보세요.

## 설치

```bash
npx skills add aiator/claude-code-tutorial --agent claude-code --yes
```

개별 에피소드만 설치하고 싶다면:

```bash
npx skills add aiator/claude-code-tutorial --skill ep01-memory --agent claude-code --yes
```

## 사전 준비

- Claude Code가 설치되어 있어야 합니다
- Claude Pro, Max, Teams, 또는 Enterprise 플랜 필요
- Node.js는 필요하지 않습니다

## 커리큘럼

### 기초 세팅

| EP | 스킬 | 주제 | 만들 것 |
|----|------|------|---------|
| 01 | `/ep01-memory` | AI에게 나를 가르치기 | 내 업무 스타일이 담긴 CLAUDE.md |
| 02 | `/ep02-skills` | 슬래시 하나로 일하기 | 유용한 스킬 3개 설치 + 실행 |
| 03 | `/ep03-mcp` | 노션/구글을 AI에 연결하기 | Claude ↔ 외부 도구 연동 |

### 스킬 제작

| EP | 스킬 | 주제 | 만들 것 |
|----|------|------|---------|
| 04 | `/ep04-create-skill` | 나만의 스킬 만들기 | 내 업무에 맞는 커스텀 스킬 |
| 05 | `/ep05-content-digest` | 콘텐츠 요약 스킬 | URL → 핵심 요약 스킬 |

### 고급 기능

| EP | 스킬 | 주제 | 만들 것 |
|----|------|------|---------|
| 06 | `/ep06-subagent` | AI 3명에게 동시에 일 시키기 | 병렬 리서치 스킬 |
| 07 | `/ep07-teams` | 혼자서 팀 운영하기 | 에이전트 팀 보고서 생성 |
| 08 | `/ep08-hooks` | 자동으로 돌아가게 | 이벤트 기반 자동화 훅 |

### 공유

| EP | 스킬 | 주제 | 만들 것 |
|----|------|------|---------|
| 09 | `/ep09-plugin` | 만든 스킬 세상에 공유하기 | 플러그인 마켓플레이스 등록 |
| 10 | `/ep10-capstone` | 나만의 AI 워크플로우 완성 | 통합 업무 자동화 시스템 |

## 실습 방법

1. 유튜브 영상을 시청합니다
2. 해당 에피소드 스킬을 설치합니다
3. Claude Code에서 `/ep01-memory` 같은 슬래시 명령을 실행합니다
4. 스킬이 단계별로 안내하면 직접 따라 만듭니다
5. 완성된 결과물은 이후 실무에서 계속 사용할 수 있습니다
