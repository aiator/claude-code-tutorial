# Block 3: AI에게 바라는 것

## WHAT TO SAY

마지막 섹션입니다.
AI가 "하면 좋은 것"과 "하면 안 되는 것"을 정해줄 겁니다.
이게 있으면 AI가 실수를 훨씬 덜 합니다.

## DO

AskUserQuestion으로 물어보세요.

### 질문 1
질문: "AI가 꼭 해줬으면 하는 것이 있나요? (여러 개 선택 가능)"
multiSelect: true
선택지:
- "모르는 건 모른다고 솔직히 말하기"
- "중요한 결정은 먼저 물어보기"
- "답변에 근거/이유 포함하기"
- Other (직접 입력)

### 질문 2
질문: "AI가 절대 하면 안 되는 것이 있나요? (여러 개 선택 가능)"
multiSelect: true
선택지:
- "확실하지 않은 정보를 사실처럼 말하기"
- "요청하지 않은 것까지 과도하게 하기"
- "이모지 남발하기"
- Other (직접 입력)

### 질문 3 (보너스)
질문: "자주 하는 반복 작업이 있나요? 예를 들면:"
선택지:
- "주간 보고서 작성"
- "이메일 초안 작성"
- "회의록 정리"
- "SNS 콘텐츠 작성"
- Other (직접 입력)

## AFTER

답변을 모아서 아래 형식으로 보여주세요:

```
## AI Behavior
- Always: {해줬으면 하는 것들}
- Never: {하면 안 되는 것들}

## Frequent Tasks
- {반복 작업 목록}
```

확인 후 Block 4로 이동.
