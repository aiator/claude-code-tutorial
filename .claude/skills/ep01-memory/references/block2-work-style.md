# Block 2: 내 업무 스타일

## WHAT TO SAY

다음은 **업무 스타일**입니다.
같은 질문을 해도 사람마다 원하는 답변 스타일이 다르죠.
"간결하게 해줘" vs "자세하게 설명해줘" — 이런 걸 미리 알려주는 겁니다.

## DO

AskUserQuestion으로 하나씩 물어보세요.

### 질문 1
질문: "AI가 답변할 때 어떤 스타일을 선호하세요?"
선택지:
- "짧고 핵심만 (3줄 이내)"
- "적당히 자세하게 (문단 단위)"
- "아주 자세하게 (예시 포함)"

### 질문 2
질문: "AI가 어떤 말투를 쓰면 좋겠어요?"
선택지:
- "존댓말 (~합니다)"
- "친근한 존댓말 (~해요)"
- "반말 (~해, ~야)"

### 질문 3
질문: "작업할 때 선호하는 언어는?"
선택지:
- "한국어"
- "영어"
- "한국어 + 코드/기술 용어는 영어"

### 질문 4 (선택)
질문: "추가로 AI에게 알려주고 싶은 업무 습관이 있나요?"
선택지:
- "아침에 집중해서 일해요"
- "마감 직전에 몰아서 해요"
- "없어요, 넘어갈게요"
- Other (직접 입력)

## AFTER

답변을 모아서 아래 형식으로 보여주세요:

```
## Communication Style
- Response length: {선호 길이}
- Tone: {말투}
- Language: {언어}
- Work habits: {업무 습관, 있으면}
```

확인 후 Block 3으로 이동.
