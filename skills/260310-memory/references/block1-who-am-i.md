# Block 1: 나는 누구인가

## WHAT TO SAY

CLAUDE.md의 첫 번째 섹션은 **"나는 누구인가"**입니다.
AI가 나를 알아야 맞춤 답변을 줄 수 있거든요.

## DO

AskUserQuestion으로 하나씩 물어보세요. 한 번에 여러 개 묻지 마세요.

### 질문 1
질문: "어떤 일을 하고 계세요?"
선택지:
- "마케팅/콘텐츠"
- "기획/PM"
- "디자인"
- Other (직접 입력)

### 질문 2
질문: "AI를 주로 어디에 쓰고 싶으세요?"
선택지:
- "문서 작성 (보고서, 기획서, 이메일)"
- "데이터 정리/분석"
- "콘텐츠 제작 (블로그, SNS)"
- Other (직접 입력)

### 질문 3
질문: "이름이나 닉네임을 알려주세요. AI가 부를 때 쓸게요."
(자유 입력)

## AFTER

답변을 모아서 아래 형식으로 보여주세요:

```
## User
- Name: {이름}
- Role: {직업/역할}
- Main use: {AI 활용 목적}
```

"이렇게 만들었어요. 수정할 부분 있으면 말해주세요."라고 말한 뒤,
AskUserQuestion으로 확인:
- "좋아요, 다음으로!" → Block 2
- "수정할게요" → 수정 후 다시 확인
